## 方案编写规范

每份技术方案应包含：
1. **背景**：业务场景和要解决的问题
2. **方案描述**：具体实现方案
3. **权衡分析**：各方案的优缺点
4. **最终结论**：为什么选择这个方案
5. **依赖影响**：对现有模块的影响
6. **实施计划**：具体的迁移/实现步骤
