## Maven 模块划分

```
aureport-ultra-server/
├── aureport-ultra-core/          # 核心引擎（纯 Java，无 Spring 依赖）
│   ├── build/                   # 报表构建器
│   │   ├── aggregate/            # 聚合计算（Sum/Avg/Count/Max/Min/Iterate）
│   │   ├── cell/                # 单元格构建（上下左右扩展填充）
│   │   ├── compute/             # 数据计算
│   │   └── paging/              # 分页处理
│   ├── chart/                   # 图表引擎（柱状/折线/饼/散点/气泡图）
│   ├── cache/                   # 报表定义缓存接口
│   ├── dsl/                    # ANTLR4 语法定义（ReportLexer.g4, ReportParser.g4）
│   ├── expression/              # 表达式解析
│   ├── model/                  # 数据模型
│   ├── parser/                 # 报表 XML 解析
│   ├── provider/               # 报表提供者（classpath/file/spring）
│   └── export/                 # 导出（Excel/PDF/Word/HTML）
│
├── aureport-ultra-web/          # Spring Boot Web 层
│   ├── controller/              # 19 个控制器
│   │   ├── designer/           # 设计器 + 数据源管理
│   │   ├── excel/             # Excel 97/2007 导出
│   │   ├── pdf/               # PDF 导出
│   │   ├── word/              # Word 导出
│   │   ├── html/              # HTML 预览
│   │   ├── image/             # 图片导出
│   │   ├── chart/             # 图表 API
│   │   ├── importexcel/       # Excel 导入
│   │   └── res/               # 资源加载
│   ├── config/                # Spring 配置（数据源、SQL 方言）
│   ├── sql/                   # 数据库方言（MySQL/Oracle/SQLServer/达梦）
```

**核心依赖关系**：`aureport-ultra-core` ← `aureport-ultra-web` ← `aureport-ultra-pub`

## 核心数据流

### 报表加载流程

```
1. 前端发起 /report/designer/loadReport
   ↓
2. Spring Controller 接收 filePath 参数
   ↓
3. ReportProvider（classpath: 或 file:）加载 .ureport.xml
   ↓
4. ReportParser 解析 XML → ReportDefinition 对象
   ↓
5. DatasetUtils 执行 SQL/Bean 方法获取数据集
   ↓
6. CellBuilder 根据 expand 方向构建单元格
   ↓
7. CellRenderer 渲染为 HTML/Excel/PDF
   ↓
8. 返回 JSON 响应给前端
```

### 单元格扩展流程

```
CellDefinition.expand = Down
↓
BindData = DatasetUtils.execute(dataset)
↓
CellBuilder.expandDown(cell, bindData)
↓
对每个数据行，复制单元格并填充数据
↓
如果 leftParentCellName 存在，
  → DataUtils.fetchData() 按父格值过滤
```

## 关键接口

### ReportProvider 接口

```java
public interface ReportProvider {
    String getPrefix();              // 返回 "classpath:" 或 "file:"
    ReportDefinition load(String path);  // 加载报表定义
}
```

实现类：
- `ClasspathReportProvider` — 从 JAR classpath 加载
- `FileReportProvider` — 从文件系统加载
- `SpringReportProvider` — 从 Spring 容器加载

### Aggregate 接口

```java
public interface Aggregate {
    BindData aggregate(List<?> data, AggregateType type,
                       String property, String nestProperty,
                       Object cellData, Context context);
}
```

实现类：
- `SumAggregate`
- `AvgAggregate`
- `CountAggregate`
- `MaxAggregate`
- `MinAggregate`
- `GroupAggregate`
- `IterateAggregate` ⭐（新增）

## 缓存机制

`ReportDefinitionCache` 接口定义报表定义缓存：

```java
public interface ReportDefinitionCache {
    ReportDefinition getReport(String key);
    void putReport(String key, ReportDefinition report);
    void removeReport(String key);
}
```

默认实现：`MemoryReportDefinitionCache`（内存缓存）

## 多数据库支持

`DialectFactory` 根据数据库类型选择对应 SQL 方言：

| 数据库 | 方言类 |
|--------|--------|
| MySQL | MySQLDialect |
| Oracle | OracleDialect |
| SQLServer | SqlServerDialect |
| 达梦 | DaMengDialect |
