# 主子表支持分析

> 本文档源自技能文档 `references/master-detail-table-support.md`，记录 Aureport Ultra 主子表实现的分析、原理和扩展。

## 引擎数据模型

### CellDefinition 核心字段

| 字段 | 作用 |
|------|------|
| `expand: Expand` | 枚举：`Down` / `Right` / `None` — 控制单元格扩展方向 |
| `leftParentCellName` | 左父格名称（纵向展开时，上方单元格） |
| `topParentCellName` | 上父格名称（横向展开时，左侧单元格） |
| `fillBlankRows + multiple` | 补空白行（每组必须对齐到 N 行） |

### BindData — 数据绑定单元

```java
public class BindData {
    private Object value;        // 显示值（单元格文本）
    private Object label;        // 映射后的显示文本
    private List<Object> dataList; // ⚠️ 关键：完整对象引用列表
}
```

`dataList[0]` 包含**当前行绑定的完整 Java 对象**（不是 ID），子格从中取嵌套属性。

## 两种主子表实现路径

### 路径 A：SQL JOIN（简单，✅ 已验证）

一个 SQL 查出扁平化数据，`expand=Down` 逐行展开。

```xml
<cell expand="Down" name="A2" col="1" row="2">
  <dataset-value aggregate="group" property="order_id" dataset-name="sales"/>
</cell>
<cell expand="Down" name="B2" col="2" row="2">
  <dataset-value aggregate="select" property="customer_name" dataset-name="sales"/>
</cell>
```

### 路径 B：双数据集 + 父子格过滤（✅ 已验证）

员工统计数据集 + 员工列表数据集，通过 `group` + `leftParentCellName` 关联。`attendance_group_detail.ureport.xml` 实战验证通过。

```xml
<!-- 员工格（主表），expand=Down，每行一个员工 -->
<cell expand="Down" name="A2" col="1" row="2">
  <dataset-value aggregate="group" property="emp_id" dataset-name="employees"/>
</cell>

<!-- 家庭成员格（子表），leftParentCellName 指向 A2 -->
<!-- 取数时 DataUtils.fetchData() 会自动按 A2 当前值过滤 familyMembers -->
<cell expand="Down" name="B2" col="2" row="2" leftParentCellName="A2">
  <dataset-value aggregate="select" property="familyMembers.name" dataset-name="employees"/>
</cell>
```

## DataUtils.fetchData() — 子格数据过滤核心逻辑

```java
public static List<?> fetchData(Cell cell, Context context, String datasetName) {
    Cell leftCell = fetchLeftCell(cell, context, datasetName); // 找左父格
    List<Object> leftList = leftCell != null ? leftCell.getBindData() : null;

    if (leftList == null) {
        return context.getDatasetData(datasetName); // 无父格 → 取全集
    }

    // ⚠️ 关键：从父格绑定的完整对象中取嵌套属性
    for (Object obj : leftList) {
        Object o = Utils.getProperty(obj, propertyPath); // 支持 dept.manager.name 嵌套
        if (o != null && o.equals(leftCell.getData())) {
            result.add(obj);
        }
    }
    return result;
}
```

## Bean 对象数据集

### XML 配置

```xml
<datasource name="empDs" type="spring" bean="employeeService">
    <dataset name="employees" type="bean" method="queryEmployees" clazz="com.example.Employee">
        <field name="id"/>
        <field name="name"/>
        <field name="department"/>
        <field name="familyMembers"/>  <!-- 嵌套 List -->
    </dataset>
</datasource>
```

### 方法签名（固定）

```java
List<T> queryEmployees(String datasourceName, String datasetName, Map<String, Object> parameters)
```

### 嵌套属性路径解析

引擎使用 `Utils.getProperty()`（基于 Apache commons-beanutils）：

```java
// ✅ 支持的路径格式
Utils.getProperty(employee, "name")                    // 简单属性
Utils.getProperty(employee, "familyMembers")            // 取整个 List
Utils.getProperty(employee, "familyMembers.relation")  // 点号嵌套

// ❌ 不支持（Apache BeanUtils 不解析数组下标）
Utils.getProperty(employee, "familyMembers[0]")         // 数组下标
Utils.getProperty(employee, "familyMembers[0].name")    // 下标 + 嵌套

// ⚠️ familyMembers.relation 会尝试调用 employee.getFamilyMembers().getRelation()
// 如果 Employee 没有 getRelation() 方法会报错
// 正确做法：用 familyMembers[0].relation
```

## Utils.getProperty() 数组下标支持（✅ 已实现 2026-05-14）

**改动文件**：`aureport-ultra-core/src/main/java/com/aureport/ultra/core/Utils.java`（line 167）

**新增语法支持**：
```java
// ✅ 现在全部支持
Utils.getProperty(employee, "familyMembers[0].name")      // 带下标 + 嵌套
Utils.getProperty(employee, "familyMembers[1].relation")    // 第二个元素
Utils.getProperty(employee, "familyMembers[2].name")       // 第三个元素
```

**实现逻辑**：
1. 按 `.` 分割路径
2. 遇到含 `[index]` 的 part，先用 `PropertyUtils.getProperty()` 取到 List
3. 再从 List 中用 `get(index)` 取元素
4. 继续处理后续嵌套属性

## GroupAggregate — 分组聚合逻辑

当子格绑定到父格后，`GroupAggregate.doAggregate()` 内部遍历 `dataList`：

```java
for (Object o : objList) {
    List<Object> rowList = new ArrayList<>();
    rowList.add(o);  // dataList 包含完整对象引用
    list.add(new BindData(data, rowList));
}
```

子格取数时，从 `rowList[0]`（Employee 对象）取 `familyMembers` 列表，再对该列表执行 `select` 聚合。

## IterateAggregate — 原生一对多嵌套迭代（✅ 已实现 2026-05-14）

**设计动机**：传统 `group` + `leftParentCellName` 方案依赖父子格过滤，配置复杂且语义不直观。`iterate` 聚合类型直接对父行对象的数组属性做迭代展开，配置最简。

**适用场景**：员工 → `familyMembers[]` 展开为多行，每个家庭成员一行。

### 聚合类型对比

| 聚合类型 | 语义 | 适用场景 |
|---------|------|---------|
| `group` | 按字段值分组，每个分组一行 | SQL 联表查、单一维度聚合 |
| `select` | 直接取数据集字段 | 简单字段展示 |
| `iterate` | 对父行嵌套数组迭代展开 | 一对多嵌套（父 Bean 含 List 字段） |

### IterateAggregate 核心流程

```
cell.getBindData() → 取父行对象列表
↓
Utils.getProperty(parent, nestProperty) → 取 familyMembers[]
↓
遍历数组元素，提取 property 字段
↓
每个元素生成一行 BindData
```

### 配置步骤（设计器 UI）

1. 选择数据集（Bean：`employeeService.queryEmployees`）
2. 聚合类型选 **"嵌套迭代"**
3. **嵌套属性**填：`familyMembers`（数组属性路径）
4. **属性**填：`name`（要显示的子字段，如家庭成员姓名）
5. 展开方向：Down

## 结论

| 需求 | 是否支持 | 方式 |
|------|---------|------|
| SQL JOIN 扁平展开 | ✅ | 一个 SQL，`expand=Down` |
| 双数据集父子格 | ✅ 已验证 | `leftParentCellName` + `DataUtils.fetchData()` |
| Bean 对象嵌套属性 | ✅ | `PropertyUtils.getProperty(obj, "familyMembers[0].name")` |
| 真正 1:N 嵌套（子表仅显示父格对应行） | ✅ 已验证 | `leftParentCellName` 过滤 + `groupstat` 聚合 |
| IterateAggregate 一对多嵌套展开 | ✅ 已实现 | `iterate` 聚合类型 |
