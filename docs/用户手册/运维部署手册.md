# 运维部署手册

> 本手册面向运维人员，介绍如何部署和运维 Aureport Ultra。

## 环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | >= 17（推荐 21） | 后端运行必需 |
| Maven | >= 3.8 | 编译打包 |
| Node.js | >= 18 | 前端构建 |
| MySQL | >= 5.7 | 仅用作数据源 |
| 内存 | >= 4GB | 推荐 8GB+ |
| 磁盘 | >= 10GB | 包含 Maven 本地仓库 |

## 项目目录结构

```
/home/coding/aureport-ultra/
├── aureport-ultra-server/     # Java 后端
│   ├── aureport-ultra-pub/   # 打包输出目录

├── aureport-ultra-ui/          # Vue 前端
│   └── dist/                   # 生产构建产物
├── reports/                    # 报表文件存储（运行时）
│   └── *.ureport.xml          # 报表模板
└── docs/                      # 项目文档
```

## 开发环境部署

### 1. 后端部署

```bash
cd /home/coding/aureport-ultra/aureport-ultra-server/aureport-ultra-pub

# 编译打包
mvn clean package -DskipTests

# 启动（默认端口 8050）
java -jar target/aureport-ultra-pub.jar

# 或指定端口启动
java -jar target/aureport-ultra-pub.jar --server.port=13000
```

### 2. 前端部署

```bash
cd /home/coding/aureport-ultra/aureport-ultra-ui

# 安装依赖（如果尚未安装）
pnpm install

# 开发模式启动（热更新）
npx vite --port 3000 --host

# 生产构建
pnpm build
```

## 生产环境部署

### 方案一：JAR + Nginx（推荐）

**后端**：
```bash
# 后台启动
nohup java -jar aureport-ultra-pub.jar --server.port=8050 \
  > /var/log/aureport.log 2>&1 &

# 配置 systemd 服务
# /etc/systemd/system/aureport.service
```

**前端 Nginx 配置**：
```nginx
server {
    listen 80;
    server_name reports.example.com;

    location / {
        root /home/coding/aureport-ultra/aureport-ultra-ui/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:8050/report;
        proxy_set_header Host $host;
    }
}
```

## 日志管理

```bash
# 查看后端日志
tail -f /var/log/aureport.log

# 查看错误日志
grep -i error /var/log/aureport.log

# 查看启动日志
grep -i "started\|error" /var/log/aureport.log
```

## 性能调优

### JVM 参数建议

```bash
java -Xms512m -Xmx2g -XX:+UseG1GC \
  -jar aureport-ultra-pub.jar
```

### MySQL 连接池

```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000
```

## 监控

- **健康检查**：`GET /actuator/health`（需启用 Spring Actuator）
- **JMX**：启用 JMX 远程监控
- **日志级别**：通过 `application.yml` 配置 `logging.level.*`
