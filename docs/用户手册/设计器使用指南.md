## 快速入门：创建第一个报表

### Step 1：新建报表

1. 打开 http://localhost:3000/report/designer
2. 点击工具栏「新建报表」按钮
3. 选择页面尺寸（如 A4、Letter）

### Step 2：配置数据源

1. 在右侧面板点击「数据源管理」
2. 点击「新增数据源」，选择类型：
   - **SQL 数据源**：填写 JDBC 连接信息 + SQL 查询
   - **Bean 数据源**：选择 Spring Bean + 方法名
3. 配置数据集，定义查询字段映射

### Step 3：设计报表布局

1. 拖拽单元格调整行列
2. 输入表头文字（如「订单号」「客户名称」）
3. 设置表头样式（加粗、背景色）

### Step 4：绑定数据

1. 点击要绑定数据的单元格（如 A3）
2. 在右侧面板选择「单元格值」配置
3. 选择数据集和字段
4. 设置聚合类型（select=普通字段、sum=求和等）
5. 设置「向下扩展」或「向右扩展」

### Step 5：预览和保存

1. 点击工具栏「预览」查看效果
2. 确认无误后点击「保存」，输入报表名称

## 常用操作

### 设置单元格扩展方向

| 扩展方向 | 说明 | 使用场景 |
|---------|------|---------|
| 无扩展 | 固定单元格 | 表头、汇总行 |
| 向下扩展 | 新行在下方追加 | 订单明细列表 |
| 向右扩展 | 新列在右侧追加 | 列转置报表 |

### 使用父子格联动

当一个单元格的值依赖于另一个单元格时，设置父子格关系：

1. 选中子格单元格
2. 在右侧面板「父子格」设置中：
   - **左父格**：选择上方单元格（纵向联动）
   - **上父格**：选择左侧单元格（横向联动）

### 使用聚合计算

在汇总行设置聚合：

1. 选中汇总单元格（如 F4）
2. 在右侧面板选择聚合类型：
   - **sum**：求和
   - **avg**：平均值
   - **count**：计数
   - **max**：最大值
   - **min**：最小值
3. 选择要聚合的字段

### 使用嵌套迭代（一对多展开）

当父对象包含数组字段（如员工的 `familyMembers[]`）时：

1. 绑定父数据集
2. 聚合类型选择「嵌套迭代」
3. 填写「嵌套属性」路径（如 `familyMembers`）
4. 填写「属性」要显示的子字段（如 `name`）

### 添加图表

1. 选中要插入图表的起始单元格
2. 点击工具栏「插入图表」
3. 在弹窗中选择图表类型（柱状、折线、饼等）
4. 配置数据绑定

### 导出报表

点击工具栏导出按钮，选择格式：
- **Excel**：导出为 .xlsx 文件
- **PDF**：导出为 PDF 文件
- **Word**：导出为 .docx 文件
- **图片**：导出为 PNG 图片

## 常见问题

### 预览页显示空白
- 等待 1-2 秒（iframe 异步加载）
- 检查 URL 参数是否正确：`reportPath=file:报表名.ureport.xml`

### 单元格数据不显示
- 确认数据集 SQL 能正常执行
- 确认字段名大小写匹配
- 确认扩展方向已设置

### 聚合结果不正确
- 确认聚合字段是数值类型（sum/avg）
- 确认单元格扩展方向正确
- 确认父子格关系设置正确
