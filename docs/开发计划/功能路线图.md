# 功能路线图

> Aureport Ultra 报表引擎功能规划

## 版本约定

- **v1.0.0**：UReport2 基线功能恢复（已完成）
- **v1.1.0**：增强功能（开发中）
- **v1.2.0~v1.3.0**：稳定性与性能优化
- **v2.0.0**：重大架构升级

---

## v1.1.0 - 增强功能（当前迭代）

### 目标
完善嵌套迭代聚合、工具栏优化、搜索表单增强

### 计划功能
- [x] IterateAggregate 嵌套迭代聚合（✅ 已完成）
- [x] Utils.getProperty() 数组下标支持（✅ 已完成）
- [x] 工具栏组件自动导入修复（✅ 已完成）
- [x] 搜索表单设计器白屏修复（✅ 已完成）
- [ ] 父子格机制完整实现与测试
- [ ] 单元格合并功能增强

### 负责人
奥力给

## v1.2.0 - 稳定性与用户体验

### 目标
提升稳定性，优化用户体验

### 计划功能
- [ ] 交叉表（Pivot Table）支持
- [ ] 报表版本管理（历史记录、回滚）
- [ ] 报表分类管理（文件夹结构）
- [ ] 报表预览加速（缓存优化）
- [ ] 单元格模板功能（预设样式）

## v1.3.0 - 企业功能

### 目标
企业级功能，增强协作与安全

### 计划功能
- [ ] 用户权限管理（用户/角色/报表级别权限）
- [ ] 报表定时任务（定时生成、邮件发送）
- [ ] 报表订阅（用户订阅报表，变更通知）
- [ ] 多数据源联合查询
- [ ] 数据集参数化（动态 SQL 参数）

## v2.0.0 - 架构升级

### 目标
重大架构升级，支持大规模企业部署

### 计划功能
- [ ] 集群部署支持（多节点报表缓存同步）
- [ ] 插件机制（自定义聚合、自定义渲染器）
- [ ] REST API 全面开放
- [ ] 插件市场（预置图表类型、数据源适配器）
- [ ] 低代码增强（参数表单可视化设计器）

待定
