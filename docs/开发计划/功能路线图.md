# 功能路线图

> Aureport Ultra 报表引擎功能规划

## 版本约定

- **v1.0.0**：UReport2 基线功能恢复（✅ 已完成 2026-05-14）
- **v1.1.0**：嵌套迭代聚合与搜索表单修复（✅ 已完成 2026-05-15）
- **v1.2.0**：值类型扩展与 WebComponent 集成（开发中）
- **v1.3.0~v2.0.0**：后续规划

嵌套迭代聚合、工具栏优化、搜索表单增强、父子格修复

- [x] IterateAggregate 嵌套迭代聚合（✅ 已完成）
- [x] Utils.getProperty() 数组下标支持（✅ 已完成）
- [x] 工具栏组件自动导入修复（✅ 已完成）
- [x] 搜索表单设计器白屏修复（✅ 已完成）
- [x] 父子格引用修复：行列操作引用更新 + BlankCellApply 重定向 + 清除内容重置（P0-1~P0-4）
