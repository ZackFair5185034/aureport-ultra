## v1.2.0 - 值类型扩展与 WebComponent 集成（当前迭代）

### 目标
扩展单元格值类型、集成 WebComponent 独立部署、HTTP 数据源标准化

### 已完成（详见 CHANGELOG）
- 单元格值类型扩展（进度条、Tooltip、GroupStat 分组聚合）
- TypeScript/ESLint 全面修复
- SpringBean 数据源增强 + Bean 自动发现 Starter 模块
- HTTP 数据源基础框架（标准协议 + 三方协议 + Proxy 代理）
- Web Component Lib 构建
- UI 组件兼容性修复（vue-simple-suggest、UCheckbox）

|--------|------|------|

## 技术债务清理

> 🔴 高 | 🟡 中 | 🟢 低 — 全部已完成 ✅

| 优先级 | 问题 | 状态 |
|--------|------|------|
| 🔴 高 | 缓存无容量/过期限制 → Caffeine/Redis 引入 | ✅ |
| 🔴 高 | SQL 执行无超时保护 → queryTimeout 配置 | ✅ |
| 🟡 中 | 异常处理粒度粗 → 完善异常信息链 | ✅ |
| 🟡 中 | 缺少 API 文档 → springdoc-openapi 引入 | ✅ |
| 🟡 中 | 数据库连接资源泄漏 → caller 判断模式 | ✅ |
| 🟢 低 | 前端状态管理类型安全 → ReportContext 索引签名 | ✅ |
| 🟢 低 | 核心循环异常保护 → MAX_ITERATIONS 常量 | ✅ |
