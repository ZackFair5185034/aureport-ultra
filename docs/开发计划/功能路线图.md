## v1.2.0 - 值类型扩展与 WebComponent 集成（✅ 已完成）

### 目标
扩展单元格值类型、集成 WebComponent 独立部署、HTTP 数据源标准化

### 已完成（详见 CHANGELOG）
- 单元格值类型扩展（进度条、Tooltip、GroupStat 分组聚合）
- TypeScript/ESLint 全面修复
- SpringBean 数据源增强 + Bean 自动发现 Starter 模块
- HTTP 数据源基础框架（标准协议 + 三方协议 + Proxy 代理）
- Web Component Lib 构建 + 独立部署集成测试
- UI 组件兼容性修复（vue-simple-suggest、UCheckbox）
- iterate 嵌套迭代字段可视化选择（下拉选择 nestProperty）
- HTTP 标准协议 Phase2 统一 Invoke 接口（POST /report/datasource/invoke）
