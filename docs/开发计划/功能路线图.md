## 技术债务清理

> 🔴 高 | 🟡 中 | 🟢 低 — 全部清理完  成 ✅

| 优先级 | 问题 | 计划版本 | 状态 |
|--------|------|----------|------|
| 🔴 高 | 缓存无容量/过期限制 → Caffeine/Redis 引入 | v1.2.0 | ✅ |
| 🔴 高 | SQL 执行无超时保护 → queryTimeout 配置 | v1.2.0 | ✅ |
| 🟡 中 | 异常处理粒度粗 → 完善异常信息链 | v1.2.0 | ✅ |
| 🟡 中 | 缺少 API 文档 → springdoc-openapi 引入 | v1.2.0 | ✅ |
| 🟡 中 | 数据库连接资源泄漏 → caller 判断模式 | v1.2.0 | ✅ |
| 🟢 低 | 前端状态管理类型安全 → ReportContext 索引签名 | v1.2.0 | ✅ |

| 🟢 低 | 核心循环异常保护 → MAX_ITERATIONS 常量 | v1.2.0 | ✅ |
