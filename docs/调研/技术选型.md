# 技术选型

> 记录 Aureport Ultra 项目中的关键技术选型决策。

## 前端技术栈

| 技术 | 选择 | 备选方案 | 决策理由 |
|------|------|---------|---------|
| 框架 | Vue 3 | React | 团队更熟悉 Vue，生态成熟 |
| 构建工具 | Vite 8 | Webpack / Rollup | 极速 HMR，开发体验好 |
| 语言 | TypeScript 5 | JavaScript | 类型安全，减少运行时错误 |
| 状态管理 | Pinia 2 | Vuex 4 | 更现代，Composition API 友好 |
| 路由 | Vue Router 4 | - | Vue 官方路由 |
| UI 组件 | 自研业务组件 | Element Plus / Ant Design Vue | 轻量化，按需定制 |
| CSS | UnoCSS | Tailwind CSS | 原子化，性能更好 |
| 图表 | Chart.js 4 | ECharts | 轻量，集成简单 |
| 表格编辑器 | Handsontable 6.2.2 | 自研 / AG Grid | 功能完整，Excel 风格 |
| 代码编辑器 | CodeMirror 5 | Monaco Editor | 轻量，表达式编辑够用 |

## 后端技术栈

| 技术 | 选择 | 备选方案 | 决策理由 |
|------|------|---------|---------|
| 框架 | Spring Boot 3.2.5 | Quarkus / Micronaut | 生态完善，团队熟悉 |
| Java 版本 | JDK 21 | JDK 17 | 最新 LTS，支持虚拟线程 |
| 构建工具 | Maven | Gradle | 团队更熟悉 |
| SQL 解析 | ANTLR4 | JCaspar / 自研 | 成熟的词法/语法解析框架 |
| Excel 导出 | Apache POI 5.2.5 | EasyExcel | 功能完整，控制粒度细 |
| PDF 导出 | iText 5.5.13.3 | OpenPDF / PDFBox | 功能完整 |
| 二维码 | ZXing |自研 | 成熟开源 |
| 数据库连接 | HikariCP | Druid | Spring Boot 默认，高性能 |
