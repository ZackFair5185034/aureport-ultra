## 调研规范

每项调研文档应包含：
1. **背景**：为什么需要调研这个问题
2. **选项**：列出所有考虑的方案
3. **评估维度**：性能、社区、License、成本、迁移工作量等
4. **结论**：明确的选择和理由
5. **参考链接**：外部资料来源
